# 茶業內部管理與績效系統 — Demo

**▶ 線上試用：https://yorroy123.github.io/teaops-demo/**

這是我為「軟體開發兼職」職缺做的作品。職缺的工作內容是「運用 AI 輔助開發，製作績效系統及公司內部管理軟體」，所以我沒有丟一個通用範例，而是直接照這個題目做了一套可以點、可以改、可以匯出的系統。

查過貴公司的營業項目是製茶與茶葉批發、零售、國際貿易，所以整套 Demo 的情境、欄位、指標都照茶業的實際流程設計。

> ⚠️ **畫面上所有公司、人員、訂單、金額皆為虛構示範資料**，與任何真實公司或個人無關，純粹用於展示系統能力。

## 這套 Demo 能做什麼

| 模組 | 內容 |
|---|---|
| **營運總覽** | 本月營收與年增率、全體平均績效、低於安全庫存品項、未結案訂單、庫存總值；月營收趨勢圖與通路營收圖 |
| **員工績效** | 8 位員工的加權評核、等第分布、細項量表、主管評語；**分數可直接拉動調整**，總分即時重算 |
| **訂單管理** | 搜尋、依狀態/通路篩選、多欄排序、新增訂單 |
| **茶品庫存** | 批號、產地、等級、安全庫存水位告警；**庫存數字可直接改**，狀態與總覽數字同步連動 |

四個模組都能匯出 CSV（含 BOM，用 Excel 開中文不會變亂碼）。

**建議試這三件事：**
1. 到「茶品庫存」把梨山冬片烏龍的庫存改成 200 → 回到「營運總覽」，低庫存磚的數字會跟著變。
2. 到「員工績效」點任一位員工 → 拉動評分滑桿，量表與加權總分即時重算。
3. 按右上角「還原示範資料」，一切回到初始狀態。

## 績效制度的設計

寫績效系統，難的不是程式，是**指標怎麼訂、誰適用哪套標準**。

如果全公司用同一張評分表，製茶師和會計永遠贏不過業務 —— 因為他們根本沒有業績數字。所以這裡做了兩套模板：

**業務型**（業務、門市、電商）

| 項目 | 權重 |
|---|---|
| 業績達成率 | 40% |
| 毛利貢獻 | 25% |
| 新客開發 | 15% |
| 客戶滿意 | 10% |
| 出勤紀律 | 10% |

**職能型**（製茶、品管、行政）

| 項目 | 權重 |
|---|---|
| 工作產出 | 40% |
| 品質穩定 | 25% |
| 流程改善 | 15% |
| 跨部門協作 | 10% |
| 出勤紀律 | 10% |

加權總分 = Σ（各項分數 × 權重）÷ 100，單項上限 130 分（超標可加分）。
等第：**A** ≥ 90、**B** ≥ 80、**C** ≥ 70、**D** < 70。

示範資料的分布是 2A / 3B / 2C / 1D —— 刻意不做成全員 A，因為一套每個人都拿 A 的績效制度沒有意義。

模板定義在 `assets/data.js` 的 `TEMPLATES`，要加項目或改權重只要改那一段，畫面與計算會自動跟上。

## 技術決策

這些選擇都是為了「交付給非技術人員也能用」：

- **零相依、零建置步驟。** 沒有 npm、沒有打包工具。`index.html` + 兩支 JS + 一支 CSS，共 4 個檔案。
- **連 `file://` 都能跑。** 刻意不用 ES module（會被 CORS 擋），改用傳統 script。下載 ZIP 解壓後直接點兩下 `index.html` 就能開，不需要架伺服器。
- **資料存在使用者自己的瀏覽器**（localStorage），不上傳任何地方。所有存取都包在 try/catch 裡，無痕模式或封鎖 storage 時會自動退回唯讀瀏覽，不會白畫面。
- **統計數字全部即時計算**，不是寫死的假數字。改了庫存或訂單，總覽的磚會跟著變。
- **圖表是手刻 SVG**，不載任何圖表函式庫。
- **深／淺色主題**：跟隨系統設定，也可手動切換，選擇會被記住。
- **響應式**，手機可用。

### 無障礙與配色

- 配色跑過色盲模擬與對比度驗證。淺色模式下部分色階低於 3:1，所以每張圖都附**直接數值標籤**與**表格檢視**切換 —— 資訊不會只靠顏色傳達。
- 狀態一律是「顏色 + 文字」成對出現（例如「● 急需補貨」），不是只給一個紅點。
- 表格可用鍵盤 Tab / Enter 操作，折線圖可用左右方向鍵逐月查看。
- 每個互動元件都有 `aria-label`。

### 測試

開發時用 jsdom 寫了 48 項煙霧測試，涵蓋渲染、篩選、排序、新增、連動更新、CSV 匯出、localStorage 持久化與還原、主題切換，全數通過。

## 在本機跑

```bash
git clone https://github.com/YORROY123/teaops-demo.git
cd teaops-demo
```

直接用瀏覽器開 `index.html` 即可。或起一個本機伺服器：

```bash
python -m http.server 8777
# 開 http://127.0.0.1:8777
```
